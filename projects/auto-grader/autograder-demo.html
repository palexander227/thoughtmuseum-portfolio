R/Python Auto-Grading Lab

This proof-of-concept demonstrates a reproducible computational grading environment for data science, statistics, and programming courses. The system accepts R scripts, Python notebooks, and RMarkdown submissions, runs automated checks, returns structured feedback, and produces instructor-facing analytics.
